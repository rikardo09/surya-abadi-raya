Panel Admin

Kelola galeri foto dan daftar customer website. Perubahan dikirim langsung ke repositori GitHub, lalu website otomatis diperbarui.

Pengaturan repositori

Belum punya token? Cara membuatnya
  1. Buka GitHub → foto profil → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Pada Repository access pilih Only select repositories lalu pilih surya-abadi-raya.
  3. Pada Permissions → Repository permissions atur Contents menjadi Read and write.
  4. Klik Generate token, salin, lalu tempel di kolom di atas.

Token hanya disimpan di browser ini dan dikirim ke GitHub saja. Jangan bagikan token kepada siapa pun.
